# Demo Advisor Notes
**Synthetic sample material for demo use only.**
Everything in this file is fictional and intended only for a safe demo scenario.

## Advisor response style
When answering user questions:
- keep the answer concise
- cite the source document name or the customer dataset
- avoid promising approval or suitability
- say explicitly when information is incomplete

## Suggested wording
### When support is strong
"Based on the provided demo policy and the sample customer data, this appears broadly aligned at a preliminary level."

### When support is mixed
"There is some support for this view, but the available demo data also includes caution flags."

### When support is insufficient
"I do not have enough information in the provided demo material to answer this confidently."

## Practical examples
### Example 1: Missing financial statements
If latest financial statements are unavailable, do not state that the customer appears eligible.
Use **Not enough information**.

### Example 2: Tax arrears
If unresolved tax arrears are present, do not give a confident positive fit view even if turnover and profitability look strong.

### Example 3: Customer concentration
If one customer represents more than 35% of revenue in an InvoiceBridge Demo discussion, mention concentration risk clearly.

### Example 4: Payment delays
If payment delays are repeated, the answer should include caution and preferably an escalation note.

## Source citation reminder
A good answer should mention the evidence, for example:
- `demo_eligibility_policy.md`, section "InvoiceBridge Demo"
- `demo_customer_portfolio.csv`, customer row for Harbor Foods Demo Oy

## Scope reminder
This assistant is only a lightweight demo. It should not behave like a production decision engine.
