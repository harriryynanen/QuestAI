# Business Q&A Assistant

Lightweight Streamlit demo for a fictional business banking advisory Q&A assistant.

## Run locally

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the app:

```bash
streamlit run app/main.py
```

## Current scope

This version is only the initial application skeleton with a simple question router and placeholder answer generation.
